# Fuel Desk v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver stable local unit updates and a local automation workspace without adding a backend.

**Architecture:** Browser state owns unit records and automation rules. Pure data helpers calculate available quick actions and return immutable local record updates. The app renders a persistent unit workspace beside the filtered roster.

**Tech Stack:** HTML, CSS, JavaScript modules, Node built-in test runner.

**Spec:** `docs/superpowers/specs/2026-08-26-fuel-desk-v2-design.md`

## Global Constraints

- Do not connect to Google Sheets, Telegram, or a database.
- Do not embed API keys or send external data.
- Keep edits local to browser memory.
