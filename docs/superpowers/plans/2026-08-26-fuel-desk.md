# Fuel Desk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a dependency-light read-only fleet fuel-management prototype with editable local state and an API-ready data adapter.

**Architecture:** Static HTML/CSS/JavaScript app. `data.js` owns records and derived domain helpers; `app.js` owns state and rendering; `styles.css` owns presentation. The UI consumes a `FleetDataSource` shaped object, making a future API or Google Sheets reader a replaceable module.

**Tech Stack:** HTML, modern browser JavaScript modules, CSS, Node built-in test runner.

**Spec:** `docs/superpowers/specs/2026-08-26-fuel-desk-design.md`

## Global Constraints

- Do not write to or connect live to the Google Sheet in v1.
- Keep all edits local to browser memory.
- Use the provided board columns as the source shape.
- No external runtime dependencies.
- App must be responsive and keyboard-usable.
